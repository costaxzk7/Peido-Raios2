# SemRaio Fabric 1.21.11 — versão 2

Esta versão usa as mappings oficiais do Mojang, em vez de Yarn, porque o Minecraft 1.21.11 mudou a situação das mappings.

## Como usar
Envie o conteúdo deste ZIP para a raiz do repositório GitHub, substituindo os arquivos anteriores. O workflow em `.github/workflows/build.yml` tenta compilar automaticamente.

Se o Actions ficar verde, baixe o artefato `SemRaio-Fabric-1.21.11` na execução e extraia o `.jar` para `%appdata%\\.minecraft\\mods`.

**Aviso:** este código ainda não foi compilado nem testado neste ambiente. Se a compilação falhar, envie a mensagem do erro. O clarão branco pode continuar mesmo se o modelo do raio for escondido.
